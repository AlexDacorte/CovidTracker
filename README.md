# 📊 COVID-19 Global Tracker

A comprehensive, real-time dashboard designed to track the spread of COVID-19 globally. This project visualizes key metrics—including total cases, recoveries, and mortality rates—through interactive maps and time-series charts.

# ✨ Features

Real-Time Statistics: Fetches latest data updates every 24 hours.

Interactive Maps: Geographic heatmaps showing hot zones and regional trends.

Country-Specific Search: Deep-dive into stats for over 200 countries and territories.

Responsive Design: Optimized for mobile, tablet, and desktop viewing.
